LOGIN AND REGISTER PROJECT

FILES
-----
index.html  - Login and registration forms
style.css   - Page layout and design
script.js   - Registration and login validation
             Uses browser Local Storage to save demo accounts

HOW TO RUN
----------
1. Extract this ZIP file.
2. Open the extracted Login-Page-With-Register folder in VS Code.
3. Open index.html in your browser, or use the Live Server extension.
4. Select Register and create an account.
5. Go to Login and enter the same email and password.

FEATURES
--------
- Register with full name, email and password
- Confirm password validation
- Prevents duplicate email registration
- Saves registered accounts in browser Local Storage
- Login succeeds only when registered email and password match
- Shows an error for incorrect login details

IMPORTANT
---------
This is a beginner frontend demo. Local Storage stores data in the browser
and this example stores passwords in plain text. It is NOT secure for real
users or production websites. Real applications need a secure backend and
proper password hashing.
